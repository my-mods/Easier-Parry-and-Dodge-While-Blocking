[size=5][b][color=#E8C88A]Easier Parry and Dodge While Blocking[/color][/b][/size]

Makes parrying more forgiving in *The Blood of Dawnwalker*. Includes native guard recovery after dodging. Attack inputs retain the base game’s guard behavior.

[list]
[*][b][color=#A8D5C2]2× parry timing window[/color][/b] by default, configurable from [b]0.1× to 50×[/b], using the game's difficulty-adjusted baseline.
[*]Keeps held guard available after a dodge, using the game's native ability lifecycle. Attack inputs retain the base game’s guard behavior.
[*]Temporarily lowers guard for a dodge and resumes when the game's combat rules allow it. Actual guard release and ability cancellation still end guarding.
[*][b][color=#A8D5C2]Dodge while blocking[/color][/b] can be turned Off in Mod Settings independently of parry timing. It defaults to On; Off blocks the player's dodge ability while block is held.
[*][b][color=#A8D5C2]Perfect dodge window[/color][/b] is independently adjustable from [b]10% to 5,000%[/b] using the native timing check. Choose from the same 20 percentages as parry. [b]100%[/b] keeps normal timing and is the default; [b]200%[/b] doubles the window. Direction and attacker-distance requirements still apply.
[*]Forward dodges use native state-change and timed completion to restore held guard. Failed or cancelled attempts release their input suppression.
[*]Native guard handling uses gameplay events. Optional Lua diagnostics observe transitions without changing guard or bindings.
[*]Parry and perfect-dodge timing accept saved changes during play and load a fresh snapshot after save loading. There is no recurring timing checker or extra Lua callback per dodge.
[/list]

Requires a Dawnwalker-compatible [b]UE4SS 3.x[/b] installation.

[size=4][b][color=#E8C88A]Installation[/color][/b][/size]

[list]
[*][b][color=#A8D5C2]Vortex:[/color][/b] Install Easier-Parry-and-Dodge-While-Blocking.zip through Vortex, enable it and deploy.
[*][b][color=#A8D5C2]Manual:[/color][/b] Copy the archive's Dawnwalker folder into ...\steamapps\common\The Blood of Dawnwalker\, preserving the folder structure.
[/list]

[size=4][b][color=#E8C88A]Settings[/color][/b][/size]

Mod Setting Menu 1.0.6+ is required. Apply saves changes and updates gameplay. Enable HookProcessConsoleExec = 1 in your Vortex-managed UE4SS configuration.

Use [url=https://www.nexusmods.com/thebloodofdawnwalker/mods/271]Mod Setting Menu 1.0.6 or later[/url] from the main menu. Press Apply to save and update the active game. See SETTINGS.md (included with the mod) for all controls, first-use import and preference backups. Console settings commands are retired.
