[size=5][b][color=#E8C88A]Easier Parry and Dodge While Blocking[/color][/b][/size]

Makes parrying more forgiving in *The Blood of Dawnwalker*. Includes native guard recovery after dodging. Attack inputs retain the base game’s guard behavior.

[list]
[*][b][color=#A8D5C2]Parry timing window[/color][/b] by default, configurable from [b]0.1× to 50×[/b], using the game's difficulty-adjusted baseline.
[*][b][color=#A8D5C2]Dodge while blocking[/color][/b] defaults to On. Off restores vanilla dodge and guard behavior, independently of parry timing. Switching waits for any active dodge to finish.
[*][b][color=#A8D5C2]Perfect dodge window[/color][/b] is independently adjustable from [b]10% to 5,000%[/b] using the native timing check. Choose from the same 20 percentages as parry. [b]100%[/b] keeps normal timing and is the default; [b]200%[/b] doubles the window. Direction and attacker-distance requirements still apply.
[*][b][color=#A8D5C2]Change mod settings live.[/color][/b] Change settings live with [url=https://www.nexusmods.com/thebloodofdawnwalker/mods/271]Mod Setting Menu[/url]
[/list]
[size=4][b][color=#E8C88A]Installation[/color][/b][/size]

[list]
[*][b][color=#A8D5C2]Vortex:[/color][/b] Install Easier-Parry-and-Dodge-While-Blocking.zip through Vortex, enable it and deploy.
[*][b][color=#A8D5C2]Manual:[/color][/b] Copy the archive's Dawnwalker folder into ...\steamapps\common\The Blood of Dawnwalker\, preserving the folder structure.
[/list]
[size=4][b][color=#E8C88A]Settings[/color][/b][/size]

Apply saves changes and updates gameplay. Enable HookProcessConsoleExec = 1 in your Vortex-managed UE4SS configuration in [b]Dawnwalker\Binaries\Win64\ue4ss[/b][b]\UE4SS-settings.ini[/b].

Use [url=https://www.nexusmods.com/thebloodofdawnwalker/mods/271]Mod Setting Menu[/url] from the main menu. Press Apply to save and update the active game. See SETTINGS.md (included with the mod) for all controls, first-use import and preference backups. Console settings commands are retired.
